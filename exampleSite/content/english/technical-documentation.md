Bad documentation costs time. Good documentation saves it.

I write technical docs and build help centers with two principles: clarity first, built to scale.

I've written user manuals, quick start guides, SOPs, conceptual guides, API/SDK docs, technical blogs, best practices, and diagrams. Beyond writing, I've also scripted, created, edited, and voiced training tutorials.

---

## Help centers

I've built multiple product help centers and API developer portals. Cortex is the help center I maintain today, and the Hyperproof developer portal still looks the way I left it. The other sites have changed since I left, so those descriptions reflect my work as it was during my time there.

### Cortex (2026 - present)

Cortex is an engineering operations (EngOps) platform that helps engineering teams track ownership, standards, and service quality. I currently own and maintain the Cortex help center.

**What I built**

- Led the migration of all documentation to a new platform in my first six months, moving the team to a docs-as-code workflow
- Rebuilt the outdated information architecture so the help center is easier to navigate and maintain
- Updated and improved help articles across the site to reflect the current product
- Created Cookbooks and recipes, as well as new API playground for endpoint testing

**See it**

- <a href="https://docs.cortex.io/" target="_blank" rel="noopener noreferrer"><strong>Cortex help center</strong></a> (live, currently maintained by me)

### Hyperproof product help center (2021 - 2025)

Hyperproof is a compliance operations platform. I was the founding technical writer and owned all documentation, from strategy and structure to writing and publishing.

**What I built**

- The original product help center, built docs-as-code with Markdown, Git, and Hugo
- A later move to Paligo, with heavy JavaScript and CSS customization
- The information architecture, taxonomy, style guide, and documentation standards behind the site

**Results**

- Reduced support requests for common workflows by 20%
- Improved feature discoverability by an estimated 52% through better taxonomy and in-app guidance

### Hyperproof developer portal (2021 - 2025)

Alongside the product docs, I built a separate developer portal for the Hyperproof API and the Hypersync SDK.

**What I built**

- The full portal, built with Redocly and based on React
- API reference and SDK guides written for developers building integrations

**See it**

- <a href="https://developer.hyperproof.app/" target="_blank" rel="noopener noreferrer"><strong>Hyperproof developer portal</strong></a> (live, still as I built it)

### Adblock Plus (2015 - 2020)

Adblock Plus is a browser extension used by over 50 million people. I was the founding technical writer and created its help center from the ground up.

**What I built**

- A docs-as-code help center aligned with the company's open source workflow
- A crowdsourced localization workflow that published docs in 20+ languages at the same time

**Results**

- Cut translation costs by nearly 75%
